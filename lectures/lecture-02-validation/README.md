## Фірмові візуальні елементи курсу

Два елементи навмисно уніфіковані, бо повертатимуться в лекціях 4, 13 і 14:

* **колірна схема розбиття** — train сталево-синій, validation вохра, test сливовий,
  витік позначається діагональним штрихуванням тривожним червоним;
* **матриця плутанини** — той самий вигляд і та сама роль кольорів (TP зелений,
  FP червоний, FN вохра, TN нейтральний).

## Приклади

Усі числові приклади взяті з відкритих публікацій, переважно з оборонної предметної
області (виявлення БпЛА за радіо-, акустичним і відеоканалом, SAR ATR, кібербезпека)
та частково зі світу LLM-агентів (контамінація бенчмарків, калібрування після RLHF,
детектори промпт-ін'єкцій). Повний перелік джерел із посиланнями — на слайді 39.

Ключові пари чисел, на яких тримається лекція:

* DroneRF, тип дрона за РЧ-сигналом: macro-F1 **0.74 → 0.46** після leave-one-recording-out
  (arXiv:2607.01025);
* EchoHawk, акустичне виявлення: P_d@FAR 5 % **0.937 → 0.875** після групування за сесією
  запису (arXiv:2606.29589);
* SWE-bench Verified, пошук файлу з багом лише за текстом issue: **76 % → 53 %**
  на репозиторіях поза бенчмарком (arXiv:2506.12286);
* GPT-4 на підвибірці MMLU: ECE **0.007 → 0.074** після RLHF (GPT-4 Technical Report);
* PromptShield: **94.8 % → 65.3 %** виявлених ін'єкцій при зниженні FPR з 1 % до 0.1 %
  (arXiv:2501.15145).

Числа наведено так, як їх подають першоджерела. Частина робіт — препринти, тож перед
лекцією варто звірити свіжі версії.
