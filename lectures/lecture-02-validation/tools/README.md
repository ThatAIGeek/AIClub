# Генератор презентації

`lecture-02-slides.pptx` зібрано скриптом на [pptxgenjs](https://gitbrent.github.io/PptxGenJS/),
щоб колоду можна було перезібрати після правок, а не редагувати 39 слайдів руками.

```bash
npm install pptxgenjs
node build.js ../lecture-02-slides.pptx
```

* `deck.js` — палітра, шрифти, геометрія, помічники (картки, смуги розбиття, матриця плутанини, схеми потоку);
* `partA.js` — слайди 1–15 (хук, навіщо розбивати, схеми крос-валідації);
* `partB.js` — слайди 16–27 (витік даних, дисбаланс, розрахунок у залі);
* `partC.js` — слайди 28–39 (метрики, калібрування, цільова метрика, чек-ліст, джерела).

Нотатки доповідача задаються полем `notes` у виклику `slide({...})` і потрапляють
у PowerPoint та Google Slides як звичайні speaker notes.
